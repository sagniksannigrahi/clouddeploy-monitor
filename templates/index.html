CI/CD pipeline

  1. 1PushCode pushed to GitHub main
  2. 2Testpytest and a Docker build run in GitHub Actions
  3. 3ShipSource package copied to EC2 over SSH/SCP
  4. 4DeployImage rebuilt and container replaced on EC2
  5. 5VerifyHealth check passes, otherwise rollback
  6. 6MonitorUptimeRobot checks /health

If any step fails, the steps after it do not run, so broken code never reaches production.
