Deployment pipeline

  1. 1PushCode pushed to GitHub main
  2. 2Testpytest runs in GitHub Actions
  3. 3BuildDocker image built and smoke-tested
  4. 4DeployRender deploy hook triggered
  5. 5MonitorUptimeRobot checks /health

If any step fails, the steps after it do not run, so broken code never reaches production.
